# 第69回 東医体スキー競技 大会公式ホームページ

第69回 東日本医科学生体育大会 冬季大会 スキー競技部門（東医体スキー競技）の公式ポータルWebサイトです。
会期は2027年3月2日〜10日、会場は長野県白馬村（アルペン：White Resort 白馬さのさか / クロスカントリー：白馬クロスカントリー競技場 スノーハープ）にて開催されます。
角丸を排したシャープでカクカクしたスタイリッシュなデザイン、明るい寒色系の青と白を基調とし、microCMS APIと連携してお知らせ・要項書類・競技日程・リザルトを動的に管理・配信できます。

## 📁 ページ構成

1. **トップページ** (`index.html`)
   - ヒーローセクション、重要リンク集、最新お知らせ（microCMS連携）、大会概要
2. **お知らせ一覧** (`news.html`)
   - カテゴリ別リアルタイムフィルター（すべて・重要・要項・日程・リザルト・その他）
   - 重要フラグON項目の赤背景強調表示
3. **大会要項・書類ダウンロード** (`documents.html`)
   - カテゴリ別書類（実施要綱、エントリーシート、コースマップ、誓約書等）のPDF/Excelダウンロード
4. **競技日程** (`schedule.html`)
   - 3月2日〜10日の白馬会場公式タイムテーブル（アルペンGS/SL、クロスカントリー、学校対抗リレー、式典）
   - 会場・交通アクセス案内（白馬さのさか、スノーハープ、白馬村ウイング21）
5. **大会結果（リザルト）** (`results.html`)
   - 種目別リザルトPDFリンク、上位入賞者プレビュー表示、過去大会アーカイブ

## ⚙️ microCMS 連携仕様

- **サービスID**: `toitai69th`
- **エンドポイント**:
  - `news`: お知らせ一覧・重要フラグ（赤背景表示対応）
  - `documents`: 大会要項・エントリー書類・コース図
  - `schedule`: 競技日程・タイムテーブル
  - `results`: 競技結果・入賞者・公式リザルトPDF

## 💻 動作環境
静的HTML5 / CSS3 / JavaScript構成のため、GitHub Pages等のホスティング環境にデプロイするだけで即座に動作します。
